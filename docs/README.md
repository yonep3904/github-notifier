# 開発者向けドキュメント

このディレクトリには、GitHub Notifier の実装を理解・変更するために必要な資料だけを置きます。
デプロイを始める場合はリポジトリ直下の [README](../README.md) 、デプロイ後の設定・利用方法はアプリケーションが提供する `/docs/ja` を参照してください。

ファイルパスの `docs/` とWebページの `/docs` を区別するため、このリポジトリでは後者を「wiki」と呼びます。

## ドキュメント

- [アーキテクチャ](./architecture.md): リクエスト、Queue、通知配送、Config 解決の構造
- [開発ガイド](./development.md): 開発コマンド、主な変更箇所、実装時の注意点

## 更新方針

公開 docs には、コードから読み取りにくく、変更時の判断に必要な情報だけを残します。
利用者向けのセットアップや設定項目は README または wiki へ記載し、一時的な調査結果や作業メモは `docs/note/` へ分離します。

次の変更を行った場合は、README、docs、wiki のうち影響するものを同時に確認してください。

- エンドポイント、認証、リクエスト形式の変更
- 環境変数や Config の既定値・検証規則の変更
- Queue、retry、通知先の変更
- 対応する GitHub イベントの変更
- デプロイ手順や必要な Cloudflare リソースの変更
